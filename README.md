# 🚀 FormMaster PHP

## 📋 Опис проекту

**FormMaster PHP** - це навчальний проект для вивчення основ PHP та роботи з веб-формами. Проект створений для практики базових концепцій серверного програмування, обробки даних форм, валідації та роботи з файлами.

## 🎯 Мета проекту

Це мій особистий навчальний проект для освоєння:

- Основ синтаксису PHP
- Обробки HTTP запитів (GET/POST)
- Валідації даних форм
- Роботи з файлами та завантаженням
- Підключення до бази даних
- Створення простих веб-додатків

## 🚀 Встановлення та запуск

### Крок 1: Встановлення XAMPP

1. Завантажте та встановіть [XAMPP](https://www.apachefriends.org/)
2. Запустіть Apache та MySQL через XAMPP Control Panel

### Крок 2: Створення бази даних

1. Відкрийте phpMyAdmin: `http://localhost/phpmyadmin`
2. Виконайте SQL скрипти для створення БД та таблиць (з вашого завдання)
3. Виконайте `add_photo_column.sql` для додавання колонки Photo:
   ```sql
   ALTER TABLE objects ADD COLUMN Photo VARCHAR(255);
   ```
4. Заповніть таблиці тестовими даними (INSERT скрипти)

### Крок 3: Налаштування підключення

1. Відредагуйте `connecta.php` за потреби:
   ```php
   $hostname = "localhost";
   $username = "labuser";
   $password = "labpass";
   $dbName   = "architecturalworkshop";
   ```

### Крок 4: Запуск проекту

1. Скопіюйте проект в директорію `C:\xampp\htdocs\xsayt`
2. Створіть директорію для фото: `C:\xampp\htdocs\xsayt\uploads\objects\`
3. Відкрийте браузер: `http://localhost/xsayt`
